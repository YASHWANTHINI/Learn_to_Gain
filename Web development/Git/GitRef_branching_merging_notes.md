#### Git References
Commits can be associated with references. A reference is a user-friendly name that points to a commit's SHA-1 value or another reference. If a reference points to another reference, it's called a symbolic reference.

![image](https://user-images.githubusercontent.com/58984578/120010578-edf64100-bffa-11eb-931b-4f1f1a7e68e4.png)

Here, the latest commit has two references associated with it, HEAD and master.

#### Branching
All commits of a project belong to a branch. By default, commit belong to the master branch. A branch is a set of commits starting with the most recent commit in the branch and tracing back to the project's first commit.
